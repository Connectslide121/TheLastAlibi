AI Detective Game – Frontend-Only Procedural Mystery System

Overview

This project is an experimental AI-powered detective game designed primarily for personal enjoyment and intellectual challenge. The goal is to create a highly replayable mystery experience where each session is procedurally generated by an LLM before gameplay begins. The generated content includes the mystery truth, suspects, clues, investigation flow, puzzle events, visual direction, and UI theme.

The core design principle is that the entire mystery is generated at the beginning of the session and remains immutable for the rest of the game. This ensures that the mystery is logically consistent and solvable while still surprising the player each time.

The game is designed to run entirely in the frontend for simplicity. It is intended for experimentation, personal play, and optional sharing with colleagues.

The system is composed of three main conceptual layers: case generation, gameplay runner, and narrative interaction.

Core Philosophy

1. The mystery must have a fixed truth generated before gameplay begins.
2. The AI generates the entire case package at the start of the session.
3. The frontend acts only as a case runner that interprets this package.
4. The LLM should never change the truth during gameplay.
5. AI is used to generate creativity and narrative, while the game engine enforces logic.
6. Every session should feel surprising, varied, and intellectually engaging.

Game Concept

The player acts as a detective investigating a mystery. Each case may involve murder, theft, disappearance, sabotage, or other unusual incidents. The player explores scenes, interviews suspects, solves puzzles, discovers clues, and eventually submits a final theory explaining what happened.

The game is designed to reward logical deduction rather than guesswork. Clues, contradictions, motives, and timelines must form a coherent puzzle that the player can solve.

Events can unlock new events depending on conditions.

Session Initialization Workflow

1. Player starts a new session.
2. Player selects visual style preference or chooses surprise mode.
3. The AI generates the complete case package including truth, events, puzzles, and visual direction.
4. The frontend stores the case package locally.
5. Images are generated using the visual direction prompt templates.
6. The investigation interface loads with the initial events unlocked.
